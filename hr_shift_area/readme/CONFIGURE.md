In order to configure shift areas you'll need to be in the _**Shift Manager**_ security
group.

## Creating areas

Go to _Shifts > Areas_ and create a new one, giving it a descriptive name.

## Assigning areas to shift templates

Go to _Shifts > Shifts_ and set the _**Area**_ field on each template.

## Assigning areas to employees

Go to _Employees > Employees_ and, in the _Work information_ tab, set the _**Areas**_
field for each employee that should be considered when generating shifts for those
areas.
