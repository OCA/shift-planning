Defines employee skill tags used to classify shift assignments, so shift
managers can quickly identify which employees are qualified for a given
shift.

**Table of contents**

.. contents::
   :local:

Configuration
=============

In order to configure skill tags you'll need to be in the **Shift
Manager** security group.

Assigning skill tags to employees
---------------------------------

Go to *Employees > Employees* and, in the *Work information* tab, set
the **Skill Tags** field for each employee. New tags can be created
directly from this field.

Usage
=====

Skill tags assigned to an employee are shown automatically in the
**Skills** column of the shift assignment kanban view (*Shifts >
Plannings*, *Shifts* smart button), so shift managers can see at a
glance which employees are qualified for a given shift.
